Nexus Design System

A minimalist, black-and-white editorial system for the Nexus blog. Plain HTML, CSS and JavaScript — every token below is exposed as a utility class and every component is a single, copy-pasteable element.

Colors

Semantic color tokens. Stored as raw HSL channels so they compose with alpha. Each has a .bg-* and/or .text-* utility.

Background.bg-background
Foreground.bg-foreground / .text-foreground
Primary.bg-primary / .text-primary
Secondary.bg-secondary
Muted.bg-muted
Accent.bg-accent
Muted Foreground.text-muted-foreground
Border.border-border
Destructive.bg-destructive / .text-destructive

Typography

Typeface is DM Sans. The type scale runs from --text-xs (12px) to --text-4xl (36px), each exposed as a .text-* utility.
