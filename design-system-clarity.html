C Clarity Design System
v1.0

Clarity

A plain HTML/CSS/JS design system for the Nexus site. Built on DM Sans, a near-monochrome palette and the indigo #575ECF brand accent. Every token below ships with a utility class you can drop straight onto markup. The full component library is rendered at the bottom of the page, grouped for the Klar visual CMS.

Each color exposes a .bg-* and/or .text-* utility class.
