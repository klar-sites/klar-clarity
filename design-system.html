A minimal, monochrome system for editorial sites.

Clarity is the visual language behind the Klar Clarity reference site — DM Sans typography, a near-black/near-white palette, and quietly confident components. Every token below is a CSS custom property; every component is plain HTML with predictable class names.

Foundations

Design tokens

All visual decisions are encoded as CSS custom properties on :root. Color values are stored as space-separated HSL channels so opacity can be applied per-usage via hsl(var(--token) / .5).

Foundations

Typography

The system uses a single typeface — DM Sans — with weight contrast carrying hierarchy. Headings are tight; body text relaxes to 1.5–1.7 line height.

displayA quiet system
h1 / 2.25remA monochrome editorial palette
h2 / 1.875remSection heading, slightly tighter
h3 / 1.5remSubsection heading
lead / 1.125remA relaxed lead paragraph that introduces the section before body copy begins.
body / 1remBody text reads at a comfortable 16px, set in DM Sans regular with a 1.5 line height. Paragraphs are constrained to roughly 60–70 characters for readable measure.

Conventions

Markup is the contract

Components are defined by their HTML structure and class names — appearance changes happen in CSS, never markup. The same blog-card pattern works in a 3-column grid, a 2-column feature row, or a sidebar list.

Semantic first

Use <article>, <nav>, <button>, <time> — never <div>-only stand-ins.

BEM-ish names

Block (.card), element (.card__title), modifier (.btn-primary). Predictable, greppable.

Tokens, not magic

No hard-coded hex codes outside :root. Every visual decision flows from a named token.
